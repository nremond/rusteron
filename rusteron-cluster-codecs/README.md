# rusteron-cluster-codecs

Aeron Cluster 1.53.3's SBE codecs for Rust, generated by sbe-tool 1.40.2 (the SBE version Aeron 1.53.3 uses):

| Module | Schema | What it encodes |
|---|---|---|
| `cluster` | `aeron-cluster-codecs.xml`, id 111, version 17 | Client sessions, the log, the consensus module and its services, snapshots |
| `mark` | `aeron-cluster-mark-codecs.xml`, id 110, version 2 | The cluster mark files |

The generated code is checked in; `./regen.sh` regenerates it from `schemas/` (needs Java and the sbe-tool and aeron-all jars, see the script).

The generated readers check only the buffer's length and panic when it is too short: code that decodes bytes it did not write checks lengths first.

## Tests

`tests/golden.rs` decodes bytes written by Aeron 1.53.3's own Java codecs (`tests/fixtures`, written by `java/GoldenCodecs.java`) and encodes them back to the same bytes. To rewrite the fixtures:

```bash
java --sun-misc-unsafe-memory-access=allow -cp ~/.m2/repository/io/aeron/aeron-all/1.53.3/aeron-all-1.53.3.jar \
  java/GoldenCodecs.java tests/fixtures
```
