# rusteron-archive-codecs

Aeron Archive 1.53.3's SBE codecs for Rust: the archive's control protocol
and its catalog structures (schema 101, version 14) and its mark file
(schema 100, version 2), generated by sbe-tool 1.40.2 from Aeron's own
schemas and checked in, so building needs no Java. `regen.sh` generates them
again; `tests/golden.rs` checks them against bytes Aeron's Java codecs wrote
(`java/GoldenCodecs.java`).

What the Rust archive server (`rusteron-archive-server`) reads and writes.
Apache-2.0, as Aeron.
